# Data, Licensing, and Privacy

## Included data

The repository includes only synthetic observations and aggregate case-study metrics. Synthetic
station identifiers and coordinates do not represent real households.

## Excluded data

The public release excludes:

- raw third-party observation payloads;
- external-provider API keys, cookies, and access tokens;
- production databases, logs, hostnames, and deployment paths;
- exact personal weather station household coordinates;
- private account, automation, and operational records;
- screenshots containing personal accounts or credentials.

## External providers

Users are responsible for complying with every provider's terms. Installing this software does
not grant a license to collect, redistribute, or commercialize third-party data.

The bundled NWS adapter is intended for public reference validation. Users must provide a
descriptive contact-bearing user agent and follow NWS request guidance.

## Responsible use

Do not use Weather X to infer private household behavior, track individuals, or combine public
observations into operational-activity intelligence.
